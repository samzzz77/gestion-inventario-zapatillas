# Sistema de Gestión e Inventario para Negocio de Zapatillas

Este proyecto es una aplicación desarrollada en Python con base de datos SQLite para gestionar el inventario, registrar ventas en tiempo real y calcular de forma automática las ganancias netas de un pequeño emprendimiento de calzado deportivo.

## 🚀 Características del Sistema
- **Base de datos relacional:** Tablas interconectadas para productos, clientes y ventas usando SQLite.
- **Menú interactivo:** Consola dinámica para navegar entre reportes y registro de ventas.
- **Cálculo de ganancias en tiempo real:** Resta automática de costos y precios finales de venta.
- **Control de stock:** Descuento automático de inventario al concretar una venta.

## 🛠️ Tecnologías Utilizadas
- Python 3
- SQLite3
- Git & GitHub

## 💻 Cómo ejecutar el programa
1. Clonar el repositorio.
2. Ejecutar en la terminal: `python negocio.py`
